📄 Formatting & Deployment Instructions

Step 1 — Build the PDF (15 min)

Option A — Canva (fastest):

1. Open Canva.com → "Create a design" → "A5 Document (Print)"
2. Add 5 blank pages
3. Paste one page of text above per page
4. Use one font (Inter, Inter Tight, or Manrope) — black + 1 accent color
5. Export as PDF
6. Save as playbook.pdf

Option B — Google Docs:

1. Create a Google Doc, set Page size to A5
2. Paste the text page by page (insert page breaks)
3. File → Download → PDF

Option C — Markdown → PDF:

1. Copy the text above into a markdown file
2. Use md2pdf.netlify.app → export
3. Install a serif font (Inter / Manrope) for cleaner look

Step 2 — Host the PDF (2 min)

Best option — GitHub Pages (free, fast):

1. In your landing page repo, create a folder /playbook/
2. Upload playbook.pdf there
3. Public URL: https://yourusername.github.io/repo-name/playbook/playbook.pdf
4. Test it loads in < 2 seconds

Backup option — Google Drive:

1. Upload to Drive
2. Right-click → Share → "Anyone with the link can view"
3. Copy link. Append &export=download to force download on mobile
4. (Slower than GitHub, but easier if you're already there)

Step 3 — Wire it into the bot

Update Script Properties → FREE_GUIDE_URL = your playbook URL.

Then verify the welcome message shows the "📥 DOWNLOAD FREE GUIDE" button by running:

```javascript
function testFreeGuideButton() {
  const cfg = getConfig_();
  Logger.log("FREE_GUIDE_URL: " + cfg.freeGuideUrl);
  if (!cfg.freeGuideUrl || !cfg.freeGuideUrl.startsWith("http")) {
    throw new Error("FREE_GUIDE_URL not set or invalid");
  }
  Logger.log("✅ Guide button will appear in /start");
}
```

Step 4 — Test the full flow (5 min)

1. Open your bot (a test Telegram account, not your admin account)
2. Send /start
3. Verify:
   · Welcome message appears
   · "📥 DOWNLOAD FREE GUIDE" button is present
   · Button opens the PDF
4. Check the FunnelTracking sheet — a new row should appear (if Meta CAPI enabled)
